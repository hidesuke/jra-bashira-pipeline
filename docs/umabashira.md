# 馬柱

レース予想の `{{umabashira}}` に入る本文です。差し込み名は [prompts.md](prompts.md)、同名で近走を特定できないときの扱いは [same-name-horses.md](same-name-horses.md) です。

冒頭は `# 馬柱` と、次の制約です。

- 各馬の近走は最大 10 走。`get_entries` を馬名で `race_meeting_date` の降順に最大 12 行取り、今回のレースと `upcoming`、開催日より未来の行を除いた残りを使う。10 走未満なら返った走だけを書く。
- 着差は `time_difference_with_winner_sec`（秒。勝者が負、敗者が正）。馬身（ハナ、アタマ、クビなど）は BASHIRA に無い。
- 着順は公式着順。正常走は「4着/14頭」と頭数（`scheduled_horse_count`。確定頭数は無い）を並べる。
- 通過順は馬ごとの 1 から 4 角の順位。レース単位の通過順文字列、各近走のラップ、調教タイムは無い。
- 同名で近走を特定できない馬は「同名馬のため近走取得不可」と、通算出走数、前走着順、前走距離、前走馬場、間隔だけを書く。近走なしとは別で、記録が無いという意味ではない。

## 馬ごとの見出し

馬は馬番の順です。見出しは `### 馬番 馬名（性・年齢・枠・斤量・騎手）` です。その次の行は調教師、その次は馬体重、その下に父と母父、今回の単勝と人気を書きます。

調教師は `調教師 名前（所属）` です。所属は `trainer_east_west` で、東を美浦、西を栗東、招待を招待と書きます。名前が無いときは `調教師 —` です。所属だけ無いときは括弧を付けません。馬体重は `馬体重 480kg（+4）` です。増減は `horse_weight_difference_with_previous_race` で、正は `+`、負はそのまま、0 は `0` です。増減が無いときは `（増減—）` です。馬体重そのものが無いときは `馬体重 —` です。取消・除外の馬にも、この 2 行を書いてから区分を書きます。

この 2 行のための列は、出馬表の `get_entries` に足します。`trainer_east_west` と `horse_weight_difference_with_previous_race` は、tools/list にあるときだけ要求します。呼び出しは増やしません。値が空でも予想は止めず、空だった馬はジョブの `raceInputGaps` に残します。馬体重の増減だけが空のときは、行に `増減—` と書き、ジョブの一覧には入れません。

`race_abnormality` が「出走取消」「発走除外」「競走除外」の馬は、その区分だけを書いて近走は出しません。この 3 つは近走の取得対象からも外れます。

近走のタスクが無い馬は「近走: 未取得」です。タスクがあり行が 0 のときは「近走なし」です。取得が打ち切られたときは「近走の取得が打ち切られました」と注記します。

## 着順の書き方

1 走は `- 日付 / 場と馬場と距離 / 馬場状態 / クラス / 着順 / 時計 / 着差 / 通過 / 上り / 騎手 / 斤量 / 人気 / 単勝` です。海外（`local_overseas_type` が JRA 以外）と天気は、あるときだけ末尾に足します。レール（`rail_type`）は距離のうしろの括弧に入ります。内コース・外コースへの読み替えはしません。

着順は次のとおりです。

- `race_abnormality` が「異常なし」のときは、その語を着順の代わりに書かない。公式着順と頭数を書く。
- 「出走取消」「発走除外」「競走除外」「競走中止」「失格」「落馬再騎乗」は、着順が無いとき、またはこの区分のときは、着順の代わりにその区分を書く。頭数があるときは「失格/14頭」のように、区分と頭数を並べる。
- それ以外で公式着順があるとき（降着など）は、公式着順を書き、区分は括弧に添える。速報（`entry_status` が `provisional`）と同着（`dead_heat`）も、あるときは括弧に添える。

生成後の着順と今回斤量の照合は [consistency.md](consistency.md) です。照合の警告は馬柱には書きません。

近10走の表（人気、単勝、レースの前半3Fと後半3F）は、馬柱とは別の `{{past_runs}}` です。同じコース・同じ競馬場・関連コースの通算は `{{course_records}}` です。形は [prompts.md](prompts.md) です。馬柱の近走行は、この表を足したあとも残します。

## 過去最高レースレベル

3歳未勝利（芝またはダート。G1、G2、G3、L、オープン、新馬、障害は除く）で、race の system にマーカー `<!-- input:race_level -->` があるときだけ、上の馬柱の末尾に空行を挟んで別の節を連結します。新しい差し込み名はありません。節の見出しは `# 過去最高レースレベル（3歳未勝利のみ）` です。各行は `馬番 馬名: ` のあとに、KV の `display` そのものです。表に無い馬は `過去最高レースレベル 不明` です。取消・除外の馬は、この節には出しません。馬柱本体の、取消・除外を区分として書く行は残します。

値の計算と KV への書き込みは、この Worker の外です。読み取るキーと、出さない条件は [prompts.md](prompts.md) です。
