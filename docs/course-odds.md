# コース集計、馬場、オッズ

## コース集計

`get_stats` の条件は開催場、馬場（芝、ダート、障害）、距離、開催年です。馬場がこの 3 つのどれでも無いときは、集計を作らずに止まります。期間の既定はレース年を含む過去 5 年（`STATS_PERIOD_YEARS`）です。レース年 2026 なら `race_year` の `gte` は 2022 です。`min_starts` の既定は 30、母父だけ 50 です。

指標は勝数（1 着の件数）、複勝圏（3 着以内の件数）、単勝払戻の合計です。

取るもの:

- 枠番（1 回、`bracket_number` で分ける）
- 4 コーナー順位を 4 回に分ける。1 から 3、4 から 6、7 から 10、11 以降
- 馬場状態（1 回、`track_condition` で分ける）
- そのレースの父（まとめて 1 回。父が一人もいなければ作らない）
- そのレースの母父（`min_starts` 50。一人もいなければ作らない）
- 騎手は 1 人ずつ 1 回。`race_abnormality` が「出走取消」「発走除外」「競走除外」の馬の騎手は除く

人気（`win_odds_rank`）では集計しません。集計条件にそのフィールドが入っていたら、実行前に止めます。該当行が 0 のタスクは「該当なし、または min_starts 未満」と注記します。

内・外はデータが無いので `course_variant` は常に null です。`rail_type` は馬柱の近走に、馬場 API の使用コースは備考に、参考として渡します。内・外には読み替えません。

成績は KV に 7 日キャッシュします。キーは `stats:v2:{id}:{場}:{馬場}:{距離}:{開始年}:{min_starts}:{対象名}` です。`id` は `bracket`、`corner:1-3`、`corner:4-6`、`corner:7-10`、`corner:11plus`、`track_condition`、`sire`、`broodmare_sire` です。騎手だけ `id` を `jockey` にまとめ、対象名で分けます。対象名は父、母父、騎手の名前を並べたもので、対象が無い集計は `-` です。キャッシュがあっても、その結果はプロンプトにも Notion にも渡しません。[pipeline.md](pipeline.md) を参照してください。

1 つの Queue メッセージで取るのは最大 8 件です。

## 馬場

馬場は `GET https://jra-dify-pipeline.hdsk.workers.dev/baba/latest` を、ジョブの最初に 1 回だけ取ります。応答の `venues[]` から、`venueName` がそのレースの開催場と一致する 1 件を使います。`fetchedAt` はそのまま残します。

同じアカウントの `workers.dev` へ Worker から global fetch すると届かず 404 になるため、`BABA` サービスバインディング（`jra-dify-pipeline`）があるときは `env.BABA.fetch` で取ります。バインディングが無いテストとローカルでは global fetch に戻します。サービスバインディングの 1 回も、Worker の外部 45 件に数えます。

失敗しても予想は続けます。HTTP ステータスと本文の先頭 200 文字を理由として残します。通信そのものが失敗したときも、そのメッセージを残して続けます。開催場が `venues` に無いときも続け、その旨を残します。

天気と馬場状態の優先順位、備考に入る項目は [prompts.md](prompts.md) です。

## 単勝オッズ

オッズは `get_odds` の単勝（`bet_type` は `win`、`race_id`、`limit` 50）です。種別（`odds_kind`）と観測時刻を日本時間でフッターに残します。取れないときは種別も時刻も「なし」と書きます。オッズが無くても予想は続けます。認可の失敗と、Durable Object の外部呼び出し上限だけは、オッズ不足として飲み込みません。

| 状況 | 理由 | 予想が使うもの |
| --- | --- | --- |
| `get_odds` が失敗し、出馬表に単勝がある | 詳細に、失敗したので出馬表の単勝を使った旨 | 出馬表の `win_odds` |
| `get_odds` が失敗し、出馬表にも単勝が無い。メッセージに「未発売」がある | 未発売 | なし |
| `get_odds` が失敗し、上のどちらでもない | 取得エラー | なし |
| 行が無く、注記に「データが無」または `2007-07-28` がある | オッズのデータが無い | なし |
| 行が無く、`live_as_of` が今より 6 時間以上古い | 取得エラー。取り込みの問題の可能性を詳細に書く | なし |
| 行が無い。上のどちらでもない | 未発売 | なし |
| 行はあるが倍率が無く、すべて `status` が `no_bets` | 発売票数なし | なし |
| 行はあるが倍率がある行が無い | 未発売 | なし |
| 倍率がある | なし（利用可能） | `get_odds` の行 |

観測時刻は行の中で最も遅い `odds_observed_at` を日本時間にしたものです。フッターの「オッズ: あり / なし（理由）」と、詳細があるときの「オッズ詳細」は [notion.md](notion.md) です。
