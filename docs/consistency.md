# 整合性チェック

レース予想の本文ができたあと、着順と今回斤量を成績と照合します。一致しないときだけ警告します。公開は止めません。警告は Notion の本文にもプロパティにも書きません。ジョブの `consistencyWarnings` とログ `prediction_consistency` に残し、`GET /admin/jobs/input` の `warnings` で読めます。

## 見る範囲

馬ごとに、その馬の節だけを見ます。節は次で区切ります。

- Markdown の見出し（`#` から `######`）と、`---` だけの行。見出しの節には馬を割り当てない。
- 行頭が、その馬名で終わる印の行。箇条書きの `-` と `*` は除いて見る。任意の「N位」、任意の印（◎ ◯ ○ ▲ ☆ △ ★）、任意の馬番のあとが馬名なら、その馬の節にする。

警告の `snippet` は、本文から切り出した一致箇所です。人が照合できるように残します。

## 着順

その馬の近走にあるレース名（2 文字以上）を、その節の中から探します。末尾が「ステークス」の名前は、「S」で終わる短い形も同じレースとして見ます。より長い別名に含まれている短い名前は、長い方を優先します。

レース名の直後、最大 40 文字、句点か改行の手前までを見ます。次のいずれなら、本文がその着順を主張したとみなします。

- 直後の「N着」（助詞「はでをにのも」が間にあってもよい）
- 直後の「勝ち」「優勝」「勝利」「制覇」「覇者」（1 着として扱う）
- 「で」のあとに続く「N着」

主張した着順が、そのレース名の公式着順（`official_result`）のどれとも違うときだけ警告します。同じレース名で公式着順が複数あれば、そのいずれかと一致すれば警告しません。レース名の例は「目黒記念」です。

## 今回斤量

節の中の `今回斤量` から 12 文字以内にある `数値 kg` を見ます。成績の `weight_to_carry_kg` との差が 0.05 kg 以上なら警告します。成績に斤量が無い馬は見ません。

出走取消、発走除外、競走除外の馬と、馬名が空の馬は照合しません。節が一つも無い馬も照合しません。同じ馬、同じ種類、同じレース、同じ主張は 1 件にまとめます。

全角数字は半角にしてから比べます。HTML のタグは除きます。
